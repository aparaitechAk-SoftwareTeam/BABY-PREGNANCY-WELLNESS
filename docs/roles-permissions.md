# Roles & Permissions

## Roles Matrix

| Role | Target Platform | Capabilities |
| --- | --- | --- |
| **Admin** | Web Portal | Full system access: users, subscriptions, content publishing, audit logs, system settings. |
| **Support Agent** | Web Portal | Ticket management, user lookup, help center moderation, escalation handling. |
| **Mother (Primary)** | Mobile App | Full maternal tracking, appointments, reports generation, family invitations, privacy controls. |
| **Partner** | Mobile App | View-only or collaborative tracking access as permitted by the mother. |
| **Family Member** | Mobile App | View shared pregnancy milestones and baby updates. |
